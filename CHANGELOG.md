# Changelog

## 2.0.3 — 2026-08-09

- Пользовательские вложения после отказа download-маршрута повторно запрашиваются через официальный inline/preview-маршрут.
- Удалён пустой параметр `post_id=` из стандартной ссылки файла.
- Двойной `HTTP 403` теперь классифицируется как `unavailable` с кодом `chatgpt_file_forbidden`.
- В итоговый ZIP добавляются `unavailable-files.md` и `unavailable-files.json` с полными метаданными недоступных файлов.
- Недоступные серверные файлы не подменяются пустыми или диагностическими файлами с исходным расширением.
- Добавлены регрессионные тесты inline fallback, серверного запрета и отчёта.

## 2.0.2 — 2026-08-09

- Исправлено падение `message is not defined` во время пакетного скачивания вложений.
- В цикле скачивания теперь сохраняется связь файла с сообщением, необходимая для interpreter URL.
- Добавлен регрессионный тест реального сценария скачивания sandbox-файла по `message_id`.
- Номер версии в графическом окне теперь берётся из константы версии и показывает `2.0.2`.

## 2.0.1 — 2026-08-09

- Исправлен HTTP 404 в проектных и общих проектных разговорах.
- Добавлено получение временного access token текущей сессии; токен не сериализуется и не попадает в предупреждения.
- Исправлено выделение канонического `g-p-...` из URL с человекочитаемым суффиксом.
- Добавлены заголовки `chatgpt-project-id` и `chatgpt-conv-owner-id`.
- Восстановлены временные метки из structured API; добавлен резервный разбор русских дат интерфейса.
- Добавлено распознавание файловых карточек без обычной ссылки `href`.
- Добавлены маршруты скачивания загруженных файлов и файлов, созданных в песочнице ChatGPT.
- Авторизованные заголовки используются только для same-origin запросов ChatGPT.
- Добавлены регрессионные тесты описанных ошибок.

## 2.0.0 — 2026-08-09

- Добавлен полноценный графический интерфейс параметров и прогресса.
- Добавлены structured acquisition и DOM fallback.
- Добавлены текущая ветка и экспорт всех обнаруженных вариантов.
- Добавлены Markdown, JSON, manifest и автономный ZIP writer.
- Добавлен best-effort экспорт доступных вложений.
- Добавлены видимые рассуждения, источники, инструменты и временные метки.
- Добавлена остановка с частичным сохранением.
- Добавлено сохранение пользовательских настроек без сохранения переписки.
- Реализовано имя `Проект - Чат`; вне проекта используется только название чата.
