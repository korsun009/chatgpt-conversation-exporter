# ChatGPT Conversation Exporter — экспорт чатов ChatGPT в Markdown, JSON и ZIP

Локальный экспортёр разговоров ChatGPT с графическими настройками, временными метками, источниками, ветками и доступными вложениями. Запускается как **bookmarklet** (закладка с JavaScript) или как постоянный **DevTools Snippet** в Яндекс Браузере, Google Chrome и Microsoft Edge.

> **English summary:** A dependency-free ChatGPT conversation exporter for Markdown, JSON and ZIP. Run it as a bookmarklet or persistent Chrome DevTools Snippet to back up messages, timestamps, citations, branches, tool metadata and accessible attachments locally.

## Для чего нужен экспортёр

ChatGPT Conversation Exporter помогает:

- сохранить важный разговор перед переносом или удалением;
- сделать резервную копию чата из обычного или проектного раздела ChatGPT;
- экспортировать ChatGPT в Markdown для чтения и заметок;
- выполнить ChatGPT JSON export для дальнейшей обработки программами;
- создать ChatGPT ZIP export с перепиской, manifest и доступными файлами;
- сохранить источники, видимые сведения об инструментах и варианты ответов;
- получить читаемый архив без передачи переписки стороннему сервису.

Экспорт выполняется непосредственно на открытой странице `chatgpt.com`. Скрипт не требует сервера, расширения браузера, npm-зависимостей или API-ключа OpenAI.

## Возможности

| Функция | Что сохраняется |
|---|---|
| Полный текст | Доступные пользовательские, системные, ассистентские и инструментальные сообщения |
| Форматы | Markdown, JSON или оба формата одновременно |
| Архив | Автономный ZIP с перепиской, `manifest.json` и доступными вложениями |
| Время | Дата и время из структурированных данных; резервный разбор русских меток интерфейса |
| Ветки | Текущая ветка либо все обнаруженные варианты сообщений |
| Источники | Цитаты, ссылки, названия и доступные фрагменты источников |
| Инструменты | Видимые метаданные вызовов инструментов и результаты, переданные странице |
| Рассуждения | Только видимые сводки рассуждений, если ChatGPT передал их странице |
| Вложения | Пользовательские файлы и файлы `/mnt/data`, если текущая сессия имеет серверный доступ |
| Проекты | Имя результата `Проект - Название чата - ChatGPT Export v2 - Дата.zip` |
| Диагностика | Режим получения данных, предупреждения и статус каждого файла в manifest |
| Остановка | Возможность остановить длинный экспорт и сохранить уже найденные данные |

Скрытый chain-of-thought, закрытая серверная трассировка и данные, не переданные браузеру, не экспортируются.

## Какой способ запуска выбрать

- **Закладка-bookmarklet** — самый быстрый запуск одним нажатием. Подходит, если браузер сохраняет длинный JavaScript URL полностью.
- **DevTools Snippet** — наиболее надёжный постоянный способ. Исходник сохраняется в профиле браузера и остаётся доступным после перезапуска.

Если bookmarklet не запускается или обрезается, используйте Snippet.

## Установка как закладки-bookmarklet

### Яндекс Браузер

1. Скачайте или откройте файл [`bookmarklet-url-v2.txt`](bookmarklet-url-v2.txt).
2. Выделите и скопируйте **всю единственную строку**. Она должна начинаться с `javascript:`.
3. В Яндекс Браузере включите панель закладок: `Ctrl+Shift+B`.
4. Нажмите правой кнопкой мыши по панели и выберите создание новой закладки. Если такого пункта нет, откройте диспетчер закладок сочетанием `Ctrl+Shift+O` и создайте закладку там.
5. Укажите название, например `Экспорт ChatGPT`.
6. В поле адреса или URL вставьте скопированную строку целиком.
7. Сохраните закладку.
8. Откройте нужный разговор на `https://chatgpt.com/`, дождитесь его загрузки и нажмите созданную закладку.

После запуска появится окно `ChatGPT Exporter v2.0.3` с настройками.

### Google Chrome и Microsoft Edge

1. Покажите панель закладок: `Ctrl+Shift+B`.
2. Откройте диспетчер закладок или добавьте любую страницу в закладки.
3. Измените созданную закладку.
4. В поле имени укажите `Экспорт ChatGPT`.
5. В поле URL вставьте полное содержимое [`bookmarklet-url-v2.txt`](bookmarklet-url-v2.txt).
6. Проверьте, что значение начинается с `javascript:` и не было обрезано.
7. Откройте разговор ChatGPT и нажмите закладку.

### Если закладка не работает

- Убедитесь, что вы запускаете её именно на `chatgpt.com`, а не на странице GitHub или в новой вкладке.
- Откройте свойства закладки и проверьте наличие начала `javascript:`.
- Некоторые браузеры ограничивают длину URL закладок. В этом случае установите постоянный DevTools Snippet по инструкции ниже.
- Не вставляйте bookmarklet в обычную адресную строку для поиска: используйте сохранённую закладку.

## Постоянная установка через DevTools Snippet

Snippet сохраняет читаемый JavaScript внутри профиля Chromium-браузера. Его не нужно вставлять заново при каждом запуске: после создания он остаётся в DevTools и доступен для любых разговоров ChatGPT.

### Создание Snippet

1. Откройте любой разговор на `https://chatgpt.com/`.
2. Откройте инструменты разработчика клавишей `F12` или сочетанием `Ctrl+Shift+I`.
3. Перейдите на вкладку **Sources / Источники**.
4. В левой панели выберите **Snippets / Фрагменты кода**.
5. Если раздел не виден, нажмите `Ctrl+Shift+P`, введите `Show Snippets` и выберите найденную команду.
6. Нажмите **New snippet / Новый фрагмент**.
7. Назовите его `chatgpt-conversation-exporter`.
8. Откройте файл [`chatgpt-conversation-exporter-v2.js`](chatgpt-conversation-exporter-v2.js), скопируйте исходник полностью и вставьте его в редактор Snippet.
9. Сохраните Snippet сочетанием `Ctrl+S`.

### Постоянный запуск сохранённого Snippet

1. Откройте нужный разговор ChatGPT и дождитесь отображения сообщений.
2. Нажмите `F12`.
3. Откройте **Sources → Snippets** или вызовите `Show Snippets` через `Ctrl+Shift+P`.
4. Выберите `chatgpt-conversation-exporter`.
5. Запустите его сочетанием `Ctrl+Enter` либо через контекстное меню **Run / Выполнить**.
6. Закройте DevTools после появления окна экспортёра — дальнейшая работа продолжится на странице.

Snippet хранится в текущем профиле браузера. Для другого профиля или другого компьютера его нужно создать отдельно.

### Обновление постоянного Snippet

1. Откройте существующий `chatgpt-conversation-exporter` в **Sources → Snippets**.
2. Удалите старое содержимое.
3. Вставьте полный исходник из новой версии [`chatgpt-conversation-exporter-v2.js`](chatgpt-conversation-exporter-v2.js).
4. Нажмите `Ctrl+S`.
5. При следующем запуске проверьте номер версии в заголовке окна.

## Использование

1. Откройте конкретный разговор ChatGPT.
2. Запустите bookmarklet или сохранённый DevTools Snippet.
3. Выберите формат: Markdown, JSON или оба.
4. Включите нужные категории: время, источники, инструменты, видимые рассуждения и файлы.
5. Выберите текущую ветку или все обнаруженные варианты.
6. Включите ZIP, если нужен единый архив.
7. Запустите экспорт и дождитесь итогового окна.

Во время длинной операции отображаются количество сообщений, источников и файлов. Кнопка остановки завершает чтение и сохраняет уже найденную часть.

### Что находится в ZIP

- `conversation.md` — читаемая переписка;
- `conversation.json` — структурированные данные;
- `manifest.json` — режим экспорта, предупреждения и статусы файлов;
- `files/` — доступные вложения;
- `unavailable-files.md` и `unavailable-files.json` — отчёты о серверно недоступных вложениях, если такие обнаружены.

## Как работает получение данных

Сначала экспортёр запрашивает структурированное дерево разговора с авторизацией текущей сессии ChatGPT. Для проектных разговоров учитываются канонический Project ID и владелец разговора. Токен используется только в памяти текущей вкладки и никогда не записывается в экспорт.

Если структурированный запрос недоступен, включается DOM fallback: скрипт прокручивает страницу и сохраняет данные, которые реально присутствуют в интерфейсе. В manifest будет указано `acquisition_mode: dom` и причина переключения.

## Вложения и HTTP 403

Файлы, созданные ChatGPT в песочнице `/mnt/data`, скачиваются через interpreter-маршрут. Пользовательские загрузки сначала запрашиваются как download, затем — через официальный inline/preview fallback.

Иногда ChatGPT сохраняет в сообщении имя, File ID и размер вложения, но файловый сервер отвечает `HTTP 403 Forbidden` даже встроенной карточке ChatGPT. Скрипт не может обойти серверные права доступа. В такой ситуации он:

- не создаёт пустой файл с исходным именем;
- присваивает статус `unavailable`;
- сохраняет File ID, Message ID, имя, размер, MIME и причину;
- добавляет отчёты `unavailable-files.md` и `unavailable-files.json`.

Восстановить содержимое такого файла можно только из локального оригинала, другого серверного архива или после исправления доступа на стороне OpenAI.

## Возможные проблемы

| Симптом | Причина и решение |
|---|---|
| Ничего не происходит | Проверьте домен `chatgpt.com`, начало `javascript:` и целостность закладки; используйте Snippet |
| Bookmarklet обрезан | Ограничение длины закладки в браузере; используйте постоянный DevTools Snippet |
| `message is not defined` | Запущена версия 2.0.1; замените закладку или Snippet на актуальный исходник |
| Structured API возвращает 404 | Обновите скрипт; старые версии неверно обрабатывали проектные URL и заголовки |
| Файл получил HTTP 403 | Сервер ChatGPT не разрешил содержимое; сведения будут в `unavailable-files.*` |
| Использован DOM fallback | Внутренний API ChatGPT изменился или недоступен; экспорт содержит только данные страницы |
| Не все временные метки найдены | В DOM fallback часть времени может существовать только во всплывающем меню |
| Нет скрытых рассуждений | Закрытый chain-of-thought не передаётся браузеру и намеренно не извлекается |
| Имя файла отличается | Запрещённые Windows-символы заменяются подчёркиванием |
| Экспорт большого чата долгий | Не закрывайте вкладку; при необходимости остановите процесс с частичным сохранением |

Внутренние маршруты и разметка ChatGPT могут изменяться без уведомления. Если появилась новая воспроизводимая ошибка, создайте GitHub Issue без публикации приватной переписки или токенов.

## Приватность и безопасность

- Экспорт выполняется локально в браузере.
- Внешние аналитические сервисы и сервер экспортёра отсутствуют.
- Переписка не сохраняется в `localStorage`; там хранятся только выбранные настройки.
- Access token текущей сессии не сериализуется и не выводится в предупреждения.
- Перед публикацией Issue удаляйте личные данные, File ID, URL приватных разговоров и содержимое экспортов.
- Запускайте код только из этого репозитория или из собственной проверенной копии.

Правила сообщения об уязвимостях описаны в [`SECURITY.md`](SECURITY.md).

## Разработка и проверка

Требуется Node.js 18 или новее. Устанавливать зависимости не нужно.

```powershell
npm test
npm run check
```

Прямая проверка без npm:

```powershell
node .\chatgpt-conversation-exporter-v2.test.js
node --check .\chatgpt-conversation-exporter-v2.js
```

Текущая версия содержит 18 регрессионных тестов, включая проектные URL, авторизованный structured API, временные метки, ветки, ZIP и разные варианты скачивания вложений.
